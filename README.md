# 🌻 Flores amarillas para Sheilla — GitHub Pages

Esta versión es HTML + CSS + JavaScript, sin Node.js. Todos los archivos están en una sola carpeta.

1. Descomprime el ZIP.
2. Sube TODOS los archivos a la raíz de tu repositorio de GitHub, reemplazando los antiguos.
3. En GitHub: Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Abre la URL de GitHub Pages y recarga con Ctrl+F5 si aparece la versión anterior.

Inicio: `index.html` (candado). Tras desbloquear, `inicio.html` es la bienvenida.
PIN: 2603. Apertura: 21/09/2026 10:10 a. m., Ecuador (UTC-05:00).
